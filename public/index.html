Distributed Architecture & Theme Mapping

1. Version Control

Repository initialized on Day 1. Granular commits track architecture, API service, UI and event flows.

2. Interoperability

Node.js backend consumes Marc Conrad's external Banana API (REST/HTTP) with mirror failover and offline fallback.

3. Event-Driven Programming

DOM listeners handle clicks, form submits, keyboard inputs and async state transitions without page reloads.

4. Virtual Identity

HttpOnly session cookies maintain player identity, role, scores and server-side puzzle solutions securely.

Data Flow:

[Browser] → (JSON) → [Node.js/Express] → (REST) → [Banana API]
