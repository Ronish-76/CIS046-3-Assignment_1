📐 Distributed Architecture & Theme Mapping

1. Version Control (Git)

Repository initialized on Day 1. Granular, meaningful commits documenting architecture, API service, UI, and event flows.

2. Interoperability

Node.js backend consumes Marc Conrad's external Banana API (REST/HTTP). Features live API calls, secondary mirror, timeouts, and fallback handling.

3. Event-Driven Programming

DOM listeners handle clicks, form submits, keyboard inputs, quick-pads, and asynchronous state transitions dynamically without page reloads.

4. Virtual Identity

HttpOnly session cookies maintain player identity, authorization role, scores, and server-side puzzle solution state securely.

Data Flow Architecture:

[Browser Client] ➔ (HTTP JSON) ➔ [Node.js / Express Server] ➔ (HTTP REST) ➔ [Remote Banana API]
